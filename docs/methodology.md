# 分析方法与口径

这份文档解释报告中的每个数字是怎么来的，方便复核、复用或替换成自己的数据。

| `invoice_date` | datetime | 交易时间 |
| `unit_price` | float | 单价（英镑） |
| `customer_id` | Int64 | 匿名客户 ID；缺失表示游客 |
| `country` | string | 客户所在国家/地区 |

派生字段：

| 字段 | 公式/规则 |
| --- | --- |

| `invoice_month` | `invoice_date` 的 `YYYY-MM` |

## 3. 清洗规则

1. **解析失败行**：发票号、SKU、数量、时间或单价无法解析的行被丢弃；本数据集为 0 行。
2. **完全重复行**：所有字段完全一致的记录只保留一次，共移除 5,268 行。
3. **有效销售**：`quantity > 0`、`unit_price > 0`，且发票号不以 `C` 开头。
4. **取消/退货**：以 `C` 开头的发票单独成表，金额取绝对值；不与销售净额相抵。
5. **商品分析**：只保留核心 SKU（5 位数字 + 可选字母后缀），排除邮费、人工调整、银行费用、礼品券等非商品行。
6. **客户分析**：RFM、复购、cohort 只使用有 `customer_id` 的销售行；游客收入保留在整体销售额中。
7. **时间边界**：数据止于 2011-12-09，12 月标记为部分月；月度取消率与 cohort 只使用完整月份。

## 4. 指标定义

| 指标 | 定义 |
| --- | --- |
| 有效销售额 | 有效销售行的 `revenue` 之和 |
| 订单数 | 有效销售行中不同 `invoice_no` 的数量 |
| 客户数 | 有效销售行中不同非空 `customer_id` 的数量 |
| 客单价 AOV | 有效销售额 ÷ 订单数 |
| 客单价中位数 | 每张订单金额的中位数，避免批发大单拉高均值 |
| 复购率 | `frequency > 1` 的客户数 ÷ 有 ID 客户数 |
| 复购收入占比 | 复购客户的 `monetary` 之和 ÷ 有 ID 客户的 `monetary` 之和 |
| 取消金额占比 | 取消发票金额绝对值之和 ÷ 有效销售额 |
| 游客收入占比 | 游客销售行收入 ÷ 有效销售额 |
| 客户集中度 | 按 `monetary` 降序，Top 10%/20% 客户的收入占比 |
| Gini | 客户消费分布的基尼系数，0 = 完全平均，1 = 极度集中 |
| Top 20% SKU 收入占比 | 按 SKU 销售额降序，前 20% SKU 的收入占比 |
| SKU 80% 覆盖率 | 累计收入首次达到 80% 所需的 SKU 数 ÷ SKU 总数 |

## 5. RFM 分层

### 5.1 打分

- **R（Recency）**：距快照日期的天数，越小越好；快照 = 数据最大日期 + 1 天。
- **F（Frequency）**：不同发票数，越大越好。
- **M（Monetary）**：历史有效销售额，越大越好。
- 每个维度按排名分成 1–5 五档；并列值用 `rank(method="first")` 稳定拆分。
- R 的分数方向反转，保证 5 分代表“最近购买”。

### 5.2 分层规则

按顺序匹配，先命中先归类：

| 客群 | 规则 | 含义 |
| --- | --- | --- |
| 冠军客户 Champions | R≥4 且 F≥4 且 M≥4 | 最近、频繁、高价值 |
| 忠诚客户 Loyal | R≥3 且 F≥3（排除冠军） | 近期仍有稳定复购 |
| 潜力客户 Potential | R≥4 且 F∈{2,3} | 近期买过 2–3 次 |
| 新客户 New | R≥4 且 F=1 | 最近首次/单次购买 |
| 流失预警 At Risk | R≤2 且 F≥3 | 曾高频，但近期沉默 |
| 沉睡客户 Hibernating | R≤2 且 F=2 | 低频且久未购买 |
| 已流失 Lost | R≤2 且 F=1 | 久未购买且仅一次 |
| 需要关注 Need Attention | 其余 | 主要是 R=3 的低频客户 |

**高价值流失预警**：R≤2 且 M≥4，单独导出为人工回访名单。

RFM 是描述性分层，不代表因果。分数会随快照日期变化，复现时请保持快照一致。

## 6. Cohort 留存

- 客户首购月 = 该客户在数据中的最早 `invoice_month`。
- 排除首购月为数据第一个月（2010-12）的客户：数据从 2010-12-01 开始，无法判断他们是否更早就是客户（左截断）。
- 对每个 cohort，计算首购后第 N 个月仍有有效购买的客户数 ÷ cohort 人数。
- 只使用完整月份；2011-12 部分月不进入留存矩阵。
- 报告中的 M1/M3/M6 为**按 cohort 人数加权的 pooled retention**，不是简单平均。
- 热力图中的空白表示“尚不可观察”，不是 0%。

## 7. 购物篮 / 关联规则

- 商品范围：按发票出现次数取 Top 60 个核心 SKU。
- 购物篮范围：至少包含 2 个不同核心 SKU 的发票。
- 对商品对 (A, B)：
  - `support = 同时包含 A、B 的订单数 ÷ 购物篮订单数`
  - `confidence(A→B) = 同时包含 A、B 的订单数 ÷ 包含 A 的订单数`
  - `lift = support ÷ (support(A) × support(B))`
- 方向选择：A→B 与 B→A 中置信度更高的一侧。
- 展示阈值：共现订单 ≥ 25，置信度 ≥ 10%，lift ≥ 1.2，按 lift 降序取前 8。
- lift > 1 表示正向关联；不是因果，也不代表组合一定提升利润，需要用实验验证。

## 8. 时间与异常说明

- **2011-12 部分月**：只有 9 天，销售额、订单数、取消率都不能与完整月份直接比较。月度图用斜线标记，取消率图直接排除。
- **批发大单**：SKU `23843` 有一张 80,995 件的订单，金额 £168,470；商品表保留它，但标注“单笔批发”，避免把它误读为常规动销。
- **1 月取消率**：2011-01 取消金额占比 19.0%，显著高于全期 8.4%，与节后退款/跨期取消有关；数据没有取消原因，不能进一步归因。
- **周六无交易**：数据中周六没有记录，可能是休息日；热力图保留空白。

## 10. 已知局限

1. 单一样本：一家英国礼品商 2010–2011 年的交易，不能代表所有电商。
2. 没有成本、毛利、履约、流量、广告、退货原因，无法计算真实利润、ROI 或 CLV 绝对值。
3. 取消金额占比是金额口径，不等同于退货率或客户流失率。
4. cohort 存在左截断，首购月为 2010-12 的客户被排除。
5. RFM 与关联规则是描述性分析；行动效果需要 A/B 测试。
6. 2011-12 只有 9 天，所有涉及该月的结论都只能作方向性参考。
